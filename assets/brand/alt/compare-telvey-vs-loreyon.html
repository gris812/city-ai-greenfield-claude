Telvey vs Loreyon: same visual system, only the name changes

Colours, Onest typeface, mark, app icon, Guides and UI are name-independent. Loreyon column is a quick mock-up, not a designed identity.

Mock-up caveat: the Loreyon wordmark is plain Onest SemiBold text next to the same mark. If you pick Loreyon I would redraw and optically space it (as was done for Telvey) before any use.
What differs: the wordmark text and its width (Loreyon is one letter longer); the name under the app icon and in the browser tab; the spoken wake phrase ("Hey Telvey" would become "Hey Loreyon"); store names, bundle id, domains and site copy. What stays identical: app icon, mark, palette, drive mode palette, type, Guides Ida and Emil, all screens.
